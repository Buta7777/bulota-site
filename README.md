# site/ — bulota.jp

静的HTML+CSSのみ(JSなし)。ビルド不要で、各HTMLをブラウザで開けばそのまま表示される。

```
index.html    トップ(料金 #price / お問い合わせ #contact はこのページ内)
works.html    事例
about.html    事業者情報
privacy.html  プライバシーポリシー
styles.css    全ページ共通
assets/icon_clean.svg  favicon
```

ヘッダーとフッターは4ページに同じものを手で置いている。直すときは4ファイルとも直す。
フッターの「最終更新」も更新のたびに直す。

## 後で差し替える箇所(index.html 内にコメントあり)

| 箇所 | やること |
|---|---|
| 代表の顔写真 | `assets/ozaki.jpg` を置き、`#profile` のコメントの手順どおりに img を出す |
| 予約ページ | `#contact` のコメントを外してURLを入れる。冒頭のボタンの href も予約ページに替える |
| ボタンの文言 | 予約URLが入ったら index.html 冒頭と works.html 末尾の「15分のヒアリングを相談する」を「予約する」に戻す |

## デザイン

2026年11月に見た目を作り直した(1回目の白地+差し色1色の版から変更)。

- 色は紺と白。紺(`--ink`)は帯・見出し・ボタン、フッターは `--ink-deep`
- 朱色(`--shu`)は数字(事例の「3時間から30分」など)と「済」の印だけに使う。ほかに広げない
- 書体は BIZ UDPGothic(Google Fonts)。本文はスマホ17px / PC 18px
- 冒頭の注文書→受注一覧の図はイメージ図(架空の取引先・品名)。写真・イラスト素材は使わない
- 色は `styles.css` 冒頭の `:root` にまとめてある

## 書いてある事実について

掲載しているのは本人から受け取った内容だけ。数字・実績・お客様の声を足すときは、事実として確認できるものに限る。

変更前の旧LPは git タグ `backup-before-redesign-2026-11-27`(と `../site_backup_2026-11-27/`)に残してある。

## お問い合わせフォーム

Googleフォームを `#contact` に iframe で埋め込み。高さは `styles.css` の `.form-panel iframe` で固定
(PC 1,400px / スマホ 1,520px / 幅360px以下 1,640px。実測した本体の高さに未入力エラーの分を足した値)。
高さが足りないと「送信」ボタンが切れて送れなくなる。質問を増やしたら、PC・スマホ・幅320pxで測り直す。
